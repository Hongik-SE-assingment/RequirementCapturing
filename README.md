# 홍익대학교 소프트웨어공학 과제 1 Requirement Capturing

* 각 팀원은 각자의 브랜치를 파서 작업한 내용을 main 브랜치로 PR을 작성한다. 
* 브랜치 네이밍은 각자의 영문 이름으로 한다. ex) KimMinA

### 기능

- 회원 가입
- 회원 탈퇴

→ 신한영

- 로그인/로그아웃
- 설문 등록/조회/삭제

→ 김민아

- 설문 검색
- 설문 상세정보 조회 및 응답

→ 유영선

- 응답한 설문 조회/수정/취소
- 통계

→ 정성훈
